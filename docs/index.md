# synth-saxs

**synth-saxs** is a lightweight Python library for simulating Small-Angle X-ray Scattering (SAXS) profiles from protein coordinates.

## Features
- **Debye Formula**: Efficient calculation of scattering intensity.
- **Solvent Model**: Physically grounded solvent displacement.
- **Educational**: Built-in plotting and scientific documentation.

## Installation
```bash
pip install synth-saxs
```
